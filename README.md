# Lintang Devfolio 🚀

A premium, highly interactive, and visually stunning developer portfolio designed with a modern **Neo-Brutalism** aesthetic. Built with React, TypeScript, Tailwind CSS, and Framer Motion.

## ✨ Features

- **Neo-Brutalist Aesthetic**: Sleek dark/light modes, thick high-contrast borders, offset hard shadows, vibrant color accents, and dynamic typography.
- **Custom Interactive Cursor**: A smooth, customized cursor that reacts to hover elements.
- **Intro Loading Screen**: Smooth preloader animation using Framer Motion.
- **Dynamic Skill Meters**: Interactive and highly visible progress indicators for technical skills.
- **Education Timeline**: A vertical pathway showcasing academic milestones.
- **Bento Grid Layout**: Clean and structured representation of developer information and setups.
- **Project Cards**: Displays recent work with tags, description, and direct links to code and live demos.
- **Interactive PDF Viewer**: Direct view and download capabilities for Resumes and Certificates of Achievement.
- **Fully Responsive**: Tailored grid layout for desktop, tablet, and mobile viewing.

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites

Make sure you have Node.js installed on your system.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ZhadeLintang/lintang-devfolio.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd lintang-devfolio
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Build the production package**:
   ```bash
   npm run build
   ```
